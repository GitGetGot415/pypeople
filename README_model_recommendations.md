# Ollama Model Recommendations

- `llama3` This seems to work the best for this project.

- `qwen2.5:3b` While it is only 1.9 GB and much faster than any of the other models listed here, the outputted text is very low quality.

- `qwen2.5:7b` Basically the same thing as qwen2.5:3b but slower. However, it does have ever so slightly higher quality output.
